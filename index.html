Input Guide & Schema Documentation

Grid Rush accepts puzzles in a simple JSON format. Below is the complete schema reference.

Full Schema

{
  "grid": [
    [0,0,0, 0,0,0, 0,0,0],  // 9 rows × 9 cols
    ...                       // 0 = empty cell
  ],
  "variants": {
    "evenodd": {
      "even": [[0,1],[3,5]],  // [row,col] 0-indexed
      "odd":  [[2,2],[4,4]]
    },
    "killer": {
      "cages": [
        { "cells": [[0,0],[0,1],[0,2]], "sum": 15 },
        { "cells": [[1,0],[2,0]],       "sum": 8  }
      ]
    },
    "thermo": {
      "thermos": [
        [[2,3],[2,4],[2,5]],  // bulb first, increasing order
        [[5,0],[6,0],[7,0]]
      ]
    },
    "arrow": {
      "arrows": [
        { "circle": [0,0], "arrow": [[0,1],[0,2],[1,2]] }
      ]
    },
    "kropki": {
      "dots": [
        { "cells": [[0,0],[0,1]], "type": "black" },  // one is 2× other
        { "cells": [[1,1],[1,2]], "type": "white" }   // consecutive
      ]
    }
  }
}

Variant Rules Summary

♟

Classic

Each row, column, and 3×3 box must contain 1–9 exactly once.

⊙

Even / Odd

Cells marked even may only contain 2,4,6,8. Cells marked odd may only contain 1,3,5,7,9.

⬡

Killer

Cells in a cage must sum to the cage total. Digits cannot repeat within a cage.

🌡

Thermo

Values must strictly increase from the bulb end to the tip of the thermometer.

→

Arrow

Digits on the arrow cells must sum to the digit in the circle. Repeats allowed on arrow.

●

Kropki

Black dot: one cell is double the other. White dot: cells are consecutive. Not all dots shown.

GUI Workflow

  1. Toggle the variant chips to activate the constraints you need.
  2. Type known digits directly into the grid cells.
  3. Use the left panel sections that appear for each active variant to enter constraints (cages, thermos, arrows, dots, even/odd marks).
  4. Click ▶ Solve. The solver will fill the grid and show step-by-step reasoning on the right.
  5. Use Export JSON to save the puzzle; Import JSON to restore one.
